# Готовые MARTS

В каталоге находятся 14 CSV-витрин, использованных в публичном дашборде
Yandex DataLens. Они содержат агрегированные аналитические данные; исходные
файлы Kaggle в репозиторий не включены.

`mart_user_360.csv` хранится через Git LFS, поскольку его размер превышает
стандартный лимит одного файла GitHub.

Проверить полный набор файлов, заголовки и число строк:

```bash
python scripts/validate_marts.py
```
